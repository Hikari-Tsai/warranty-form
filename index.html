保固條款與注意事項

  1. 自購買日起享有本公司保固與技術服務一年，但下列狀況不在保固範圍內：
    1. 無法證明為群彩文創有限公司／揚聲堡音樂代理產品之公司貨
    2. 電源線與其連接之變壓器
    3. 產品上之耗材（如電池、指示燈、外觀之損耗與消耗性產品之損壞）
    4. 產品上之控制轉鈕、琴鍵、按鍵、可變電阻、插孔、電池蓋、開關、配件等脫落或遺失
    5. 產品被任何非本公司或本公司授權簽約之技術人員（包括消費者本人）所執行之修理、調整或改造，或已拆開過產品本體者，皆視同自行拆機，保固自動失效
  2. 若有下列情況發生，本公司須依實際情況收取零件與人工費用：
    1. 因天災、人禍而損壞者（如泡水、摔機等）
    2. 由於使用不當或不慎，導致產品故障或毀壞者
    3. 未依規定使用電源電壓所導致之損壞
    4. 保固期內之運費與維修人員出勤費本公司得酌收之
  3. 超出保固期限與條件，本公司將收取維修費用。
  4. 產品未登入註冊或經查明後發現非本公司進口銷售之貨品，本公司保有不提供維修服務的權利。
  5. 本公司保有保固維修相關之最終判定權。
